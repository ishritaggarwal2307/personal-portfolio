Project description:
This is a responsive personal portfolio website created using HTML5 and CSS3. It includes Home, About, Skills, Projects, and Contact sections with semantic HTML, navigation anchors, reusable CSS variables, card layouts, hover and focus states, and media queries for smaller screens. The portfolio presents my education, current learning interests, and selected learning/research work. The website uses no JavaScript, frameworks, backend, or database.

This project follows the requirements in the supplied HTML & CSS Internship Project Guide.
